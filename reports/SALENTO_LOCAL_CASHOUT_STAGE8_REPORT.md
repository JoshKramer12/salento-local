## Independent control and safe drill

New independent control code enumerates all platform transfers and all payouts on connected accounts visible to the active Stripe mode since an explicit activation timestamp. It compares provider IDs, metadata, amount, currency, mode, destination, durable attempts and commission allocations, detects unexpected objects, missing recorded accounts and reversals, and captures platform/connected EUR balance snapshots. Old test-account profile IDs therefore do not make a live-key scan query inaccessible test accounts; a withdrawal tied to an inaccessible account is a critical incident. It uses Stripe and SQLite **read calls only** and fails closed on API errors, an excluded local withdrawal or scan limits. A separate scheduler wrapper records successful worker/reconciliation runs in a private atomic state file, detects missing runs, delivers keyed alerts to a configured authenticated sink, retries failed delivery, deduplicates delivered incidents, and supports explicit acknowledgment. No production schedule, alert sink, recipient or state file was configured. The control process itself still needs an external failed/missing-run monitor; balance snapshots are not an independently signed bank/Stripe statement reconciliation.

In a safe local drill using a mock worker/health endpoint and a local alert sink, the **genuine Stripe test-mode read-only inventory** found one withdrawal, one transfer and one payout, all €50 and initially no variance. The final scanner also enumerated both Stripe connected accounts in the sandbox. Missing worker and reconciliation runs generated two alerts; a second scan delivered zero duplicates. Mock successful run receipts cleared those incidents. An intentional alert-sink 401 left one reopened incident pending; the next successful scan delivered it once and a repeat scan delivered zero. After the real 1-cent Stripe reversal, the same provider scan detected it, and isolated reconciliation held the withdrawal. The mock worker/alert endpoint in this drill is distinct from the genuine Stripe inventory and genuine webhook delivery.
